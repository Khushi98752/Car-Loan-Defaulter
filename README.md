# Car-Loan-Defaulter
This project focuses on developing a robust predictive model to identify borrowers at high risk of loan default, utilizing advanced machine learning techniques to optimize credit decisions, enhance risk management, and improve portfolio performance. The analysis is based on the "Automobile Loan Default" dataset and involves comprehensive data preprocessing, exploratory analysis, and feature engineering to uncover significant patterns influencing loan default. Various models, including logistic regression, decision trees, random forests, gradient boosting, and XGBoost, were evaluated for performance. Techniques such as resampling, class weighting, and threshold tuning were implemented to address class imbalance and improve minority class prediction. This project is a step toward more reliable and efficient credit risk assessment in financial lending.
